# 🥦 Vegz – Vegetable Marketplace

Vegz is a digital vegetable marketplace that connects **customers, vegetable sellers, and delivery agents** in one platform.

## 🚀 Features

* 👤 Customer registration & login
* 🥕 Browse vegetables and prices
* 🛒 Add vegetables to cart and place orders
* 💳 Online payment integration
* 🏪 Seller management and product listing
* 🚚 Delivery agent order management
* 📍 Address and delivery management
* 🔐 OTP/JWT-based authentication

## 🏗️ Architecture

* **Frontend:** React / Android
* **Backend:** Node.js / Python
* **Database:** MySQL
* **Payment:** Razorpay
* **OTP:** MSG91
* **Deployment:** Docker & Docker Compose
* **Cloud:** AWS
* **CI/CD:** Jenkins + GitHub

## 🔄 Order Flow

**Customer → Order → Payment → Seller → Delivery Agent → Customer**

## 🎯 Goal

To provide a simple and reliable platform for buying and selling fresh vegetables with efficient order and delivery management.
